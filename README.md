## Overview

**Do It Later** is a lightweight browser companion that docks into your browser's native side panel. It captures selected text, URLs, and spontaneous thoughts from your desktop and sends them straight to your mobile app inbox.

- **Zero OAuth configuration**: Authenticates using a permanent 6-digit sync code generated by the mobile app.
- **Side Panel native**: Docks alongside your active browser tab without obscuring page content.
- **Staging queue**: Review or edit thoughts locally before dispatching them to your phone.
- **History archive**: Records dispatched clips with delivery status and timestamps.

## Installation

### 1. Clone or Download

```bash
git clone https://github.com/CODEMASTERSTACK/DoitLater-Extension.git
```

*Or download the repository ZIP file and extract it locally.*

### 2. Load into Your Browser

1. Open your browser's extension manager:
   - **Chrome**: `chrome://extensions`
   - **Edge**: `edge://extensions`
   - **Brave**: `brave://extensions`
   - **Arc**: `arc://extensions`
2. Enable **Developer mode** using the toggle switch in the top-right corner.
3. Click **Load unpacked** and select the repository folder.
4. Pin **Do It Later** to your browser toolbar for quick side panel access.

---

## Mobile Pairing

1. Open **Do It Later** on your mobile device and sign in.
2. Navigate to the **Study** tab and tap the **Laptop icon** next to the search bar.
3. Note your permanent **6-digit sync code**.
4. Open the **Do It Later** sidebar in your browser, enter the 6-digit code, and click **Connect Account**.

## Architecture

```
[ Webpage Selection / Input ]
              │
              ▼
[ Chromium Side Panel (popup.js) ]
              │
              ▼
[ Cloudflare Worker API Proxy ]
              │
              ▼
[ Firebase / Firestore Cloud Vault ]
              │
              ▼
[ Do It Later Mobile App Inbox ]
```

- **Client Security**: No private database credentials or API keys exist in the client code.
- **Edge Proxy**: Requests are verified and processed through a Cloudflare Worker proxy.
- **User Isolation**: Data writes strictly target the authenticated user's private inbox collection.
